4. CÓMO OBTENER LA ACTUALIZACIÓN — PC
Si no tiene el repositorio:
  git clone --branch acevedo_perez_velandia https://github.com/Felipe-Acevedo-UMNG1/Parcial-2.git
  cd Parcial-2
Si ya lo tiene, primero guarde sus cambios locales; después:
  git fetch origin
  git switch acevedo_perez_velandia
  git pull --ff-only origin acevedo_perez_velandia
Compruebe git status: debe indicar la rama del equipo.
Los .env privados NO cambian con git pull. Si existen, editar únicamente:
  backend/.env: GRUPO_CODIGO=SI26-G02, APP_PORT=8102, DB_PORT=33062.
  frontend/.env: APP_PORT=8102.
Conservar IPs, contraseñas, JWT_SECRET y demás valores privados que ya sean correctos.
Si no existen .env, copiar los .env.example respectivos y completar sus <...>.
MySQL/firewall/ACL ya instalados también necesitan actualizarse y aplicarse.
